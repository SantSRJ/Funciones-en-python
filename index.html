    Nota para el docente

    Antes de tocar los botones, pedí que señalen las partes en el pizarrón. Insistí con dos convenciones de la cátedra: el nombre lleva un verbo en infinitivo que describa la tarea (calcularpromedio, leerfecha) y el cuerpo se define solo por la sangría: no hay llaves ni end.

    Reglas para el nombre y la cabecera

    • El nombre sigue las mismas reglas que las variables: letras, números y _, sin empezar con número ni usar palabras reservadas.
    • Se recomienda un verbo en infinitivo: calcular_area, es_par, leer_entero.
    • Los parámetros van entre paréntesis y separados por comas. Puede haber cero o más.
    • La cabecera termina con : y el cuerpo va indentado 4 espacios.
    • Evitá nombres de funciones internas (max, sum, list): las “tapás” y dejan de funcionar.
    Alerta de error típico: olvidar los paréntesis al llamar

    resultado = calcularpromedio no ejecuta la función: guarda la función misma en la variable. Al imprimir vas a ver <function calcularpromedio at 0x...>. Para invocarla siempre van los paréntesis: calcularpromedio(x, y).

    Detenete en el paso donde aparece el recuadro de calcularpromedio: a y b son copias de los valores de x e y, no las mismas variables. Y en el último paso, preguntá: “¿Puedo hacer print(total) en el programa principal?”. La respuesta (no, total ya no existe) introduce el ámbito del Módulo 3.
     Flujo de ejecución
    Python ejecuta las sentencias de arriba hacia abajo. Un def no ejecuta el cuerpo: solo crea la función. El cuerpo corre recién cuando alguien la llama; ahí el flujo “se desvía” hacia la función y, al terminar, vuelve al punto donde estaba.

     Parámetros opcionales
    Un parámetro con =valor en la cabecera es opcional: si la llamada no lo envía, toma ese valor. Así una misma función sirve para el caso común y para los casos especiales.
    

    Los parámetros con valor por defecto van después de los obligatorios: def f(a, b=2) es válido, def f(a=1, b) no.

    2.5Errores en la llamada y paso de listas4 min
    

     La cantidad tiene que coincidir
    Si faltan o sobran argumentos, o se usa un nombre que no existe, Python lanza TypeError en el momento de la llamada. El mensaje dice exactamente qué pasó: missing 1 required positional argument, takes 2 positional arguments but 3 were given, unexpected keyword argument.
    

    ¿Qué recibe la función: el valor o la variable? Recibe una referencia al mismo objeto. Con números y textos no se nota, porque son inmutables. Pero si la función recibe una lista y la modifica, el cambio se ve afuera: es el aliasing de la clase de listas.
     Alerta de error típico: modificar sin querer la lista recibida
    Si la función debe devolver una lista nueva (por ejemplo, filtrada), creá una lista nueva adentro y no toques la que recibiste. Quien la llamó no espera que su lista cambie.

    3.2No colocar return dentro de un ciclo4 min
    

     Una regla de la cátedra
    Se considera una mala práctica colocar un return dentro de un ciclo: el ciclo tiene dos salidas (la condición y el return) y el código se vuelve difícil de seguir. La forma correcta es dejar que el ciclo termine por su condición y devolver al final.
    

    Para búsquedas, en lugar de “cortar con return cuando lo encuentro”, se usa una bandera o se agrega la condición al while: while i < len(lista) and not encontrado:.
     Nota para el docente
    Los dos bloques dan el mismo resultado con los mismos datos de entrada. Pedí que comparen la cantidad de salidas de cada ciclo y la cantidad de return. Esta regla aparece en todas las soluciones de la práctica.
    def leerysumar():
    suma = 0
    n = 0
    while n != -1:
        n = int(input("Ingresá un número entero o -1 para terminar: "))
        if n == -1:
            return suma                # return DENTRO del ciclo: mala práctica
        suma = suma + n

# Programa principal
total = leerysumar()
print("La suma de los valores ingresados es", total)
    def leerysumar():
    suma = 0
    n = int(input("Ingresá un número entero o -1 para terminar: "))
    while n != -1:
        suma = suma + n
        n = int(input("Ingresá un número entero o -1 para terminar: "))
    return suma                        # un único return, al final

# Programa principal
total = leerysumar()
print("La suma de los valores ingresados es", total)
    


    3.3Ámbito de las variables7 min
    

     Cada función tiene su propio espacio
    Las variables creadas dentro de una función (incluidos sus parámetros) son locales: nacen cuando la función se llama y desaparecen cuando termina. Las del programa principal no deben usarse dentro de las funciones, y viceversa.
    

    Por eso hace falta el circuito parámetros → función → return: es la única comunicación correcta entre los dos mundos.
     Alerta de error típico: usar variables del programa principal
    Una función sin parámetros que lee x e y “de afuera” funciona por casualidad: depende de que existan variables con esos nombres y su resultado cambia sin que la llamada cambie. No se puede reutilizar en otro programa. Todo dato que la función necesite debe pasarse como parámetro.
     Alerta de error típico: modificar una variable global
    Si una función asigna una variable con el mismo nombre que una global, Python la considera local en toda la función. Leerla antes de asignarla da UnboundLocalError. Existe la palabra global para forzarlo, pero en la materia no se usa: se pasa el valor como parámetro y se devuelve el nuevo.

    3.4Reglas de estilo y el programa completo6 min
    

     Lo que pide la cátedra
      

    • Las funciones se escriben antes del programa principal. Ni durante, ni después.
      • 

    • Una línea en blanco antes de cada función y entre la última función y el programa principal.
      • 

    • Un comentario # Programa principal que indique dónde empieza.
      • 

    • Cada función realiza una sola tarea. Si calcula, solo calcula: el input() y el print() no forman parte de ella (salvo que su tarea sea justamente leer o mostrar).
      • 

    • Todo dato se recibe por parámetro y todo resultado se devuelve con return.
      • 

    • Un solo return, fuera de los ciclos.
      • 

    • Recomendado: un docstring ("""...""") en la primera línea del cuerpo que explique qué hace.
     Nota para el docente
    Este es el “programa completo” del material (ejemplos 2 a 6). Muestra tres novedades a la vez: una función sin parámetros (leerfecha()), una que devuelve tres valores y una función que llama a otra (leerfecha usa leerentero). Los datos de entrada incluyen un mes fuera de rango (13) para ver la validación.
    def leerentero(minimo, maximo):
    """Lee un entero por teclado hasta que esté entre minimo y maximo."""
    print("Ingresá un número entero entre", minimo, "y", maximo, ": ", end="")
    a = int(input())
    while a < minimo or a > maximo:
        print("Valor incorrecto. Debe estar entre", minimo, "y", maximo)
        a = int(input("Ingresá un número entero: "))
    return a

def calcularedad(dnac, mnac, anac, dact, mact, aact):
    """Devuelve la edad cumplida a la fecha actual."""
    edad = aact - anac
    if mact < mnac:
        edad = edad - 1
    elif mact == mnac and dact < dnac:
        edad = edad - 1
    return edad

def leerfecha():
    """Lee día, mes y año validados. Devuelve los tres valores."""
    print("Día? ", end="")
    dia = leerentero(1, 31)
    print("Mes? ", end="")
    mes = leerentero(1, 12)
    print("Año? ", end="")
    anio = leerentero(1583, 2100)
    return dia, mes, anio

    def multiplicar(a, b):
    """Devuelve a * b usando solo sumas."""
    resultado = 0

    return resultado

def potencia(a, b):
    """Devuelve a elevado a b (b >= 0) usando multiplicar()."""
    resultado = 1
    for _ in range(b):
        resultado = multiplicar(resultado, a)
    return resultado

def buscar(lista, elemento):
    """Posición de la primera aparición, o -1 si no está."""
    i = 0
    while i < len(lista) and lista[i] != elemento:
        i += 1
    if i == len(lista):

    return i

    return unicos

    def contar_digitos(numero):
    """Cantidad de dígitos de un entero (el 0 tiene uno)."""
    n = abs(numero)
    cant = 1
    while n >= 10:
        n = n // 10
        cant += 1
    return cant

def extraerdigito(numero, posicion):
    """Dígito en la posición indicada (0 = unidades), o -1 si no existe."""
    if posicion < 0 or posicion >= contar_digitos(numero):
        digito = -1
    else:
        digito = (abs(numero) // 10 ** posicion) % 10
    return digito

def digitocentral(numero):
    """Dígito central si la cantidad de dígitos es impar; -1 si es par."""
    cant = contar_digitos(numero)
    if cant % 2 == 0:
        central = -1
    else:
        central = extraerdigito(numero, cant // 2)
    return central

    (TP 6, ejercicios 7 y 8) Escribí mcd(x, y) basándote en: MCD(X, X) = X; MCD(X, Y) = MCD(Y, X); si X > Y, MCD(X, Y) = MCD(X − Y, Y). Usala para mcm(x, y). Después, raiz_newton(n, tolerancia=0.0001), que aplique la fórmula de Newton a = (a + n / a) / 2 desde a = n / 2 hasta que dos aproximaciones sucesivas difieran menos que la tolerancia, y que devuelva la raíz y la cantidad de iteraciones.
    
  
     Tu solución
    
  
    
  
     Ver pista
    El MCD se resuelve con un while x != y que resta el menor al mayor. Para Newton, guardá la aproximación anterior antes de calcular la nueva y comparalas con abs().
    
  
     Ver solución explicada
    1. mcd: mientras x != y, al mayor le restás el menor. Cuando son iguales, ese es el MCD. Guardián: si alguno es 0, el MCD es el otro.
    2. mcm(x, y) = x * y // mcd(x, y): una función que reutiliza otra.
    3. raiz_newton: anterior = n / 2, calcular actual, y repetir mientras abs(actual - anterior) >= tolerancia.
    4. Devolver actual, iteraciones: una tupla con dos resultados.
    5. El parámetro por defecto permite pedir más precisión sin cambiar la función: raiz_newton(2, tolerancia=1e-10).
    xyOperación
    4015x > y → x = 40 − 15
    2515x > y → x = 25 − 15

    105x > y → x = 10 − 5

    def mcd(x, y):
    """Máximo común divisor de dos enteros no negativos, por restas sucesivas."""
    if x == 0 or y == 0:
        resultado = x + y
    else:
        while x != y:
            if x > y:
                x = x - y
            else:
                y = y - x
        resultado = x
    return resultado

def mcm(x, y):
    return x * y // mcd(x, y)

def raiz_newton(n, tolerancia=0.0001):
    """Raíz cuadrada aproximada de n > 0. Devuelve (raiz, iteraciones)."""
    anterior = n / 2
    actual = (anterior + n / anterior) / 2
    iteraciones = 1
    while abs(actual - anterior) >= tolerancia:
        anterior = actual
        actual = (anterior + n / anterior) / 2
        iteraciones += 1
    return actual, iteraciones

# Programa principal

def leer_notas():
    """Lee notas separadas por comas hasta que todas sean válidas (1 a 10)."""
    notas = None
    while notas is None:
        texto = input("Notas separadas por comas: ")
        try:
            candidatas = [float(x) for x in texto.split(",")]
            if all(1 <= n <= 10 for n in candidatas):
                notas = candidatas
            else:
                print("  Las notas van de 1 a 10")
        except ValueError:
            print("  Solo se admiten números")
    return notas

def calcular_promedio(notas):
    return sum(notas) / len(notas)

def esta_aprobado(notas, minimo=6):
    return calcular_promedio(notas) >= minimo

def buscar_alumno(datos, nombre):
    """Devuelve el nombre guardado que coincide (sin mayúsculas) o None."""
    encontrado = None
    for guardado in datos:
        if encontrado is None and guardado.lower() == nombre.strip().lower():
            encontrado = guardado
    return encontrado

def agregar_alumno(datos):
    nombre = input("Nombre: ").strip()
    if nombre == "" or buscar_alumno(datos, nombre) is not None:
        print("  Nombre vacío o repetido")
    else:
        datos[nombre] = leer_notas()
        print("  Agregado:", nombre)

def mostrar_alumnos(datos):
    if not datos:
        print("  No hay alumnos cargados")
    for nombre, notas in sorted(datos.items()):
        estado = "Aprueba" if esta_aprobado(notas) else "No aprueba"
        print(f"  {nombre:<8} {calcular_promedio(notas):5.2f}  {estado}")

def ranking(datos):
    pares = [(nombre, calcular_promedio(notas)) for nombre, notas in datos.items()]
    return sorted(pares, key=lambda t: t[1], reverse=True)

def eliminar_alumno(datos, nombre):
    guardado = buscar_alumno(datos, nombre)
    if guardado is not None:
        del datos[guardado]
    return guardado is not None

datos = {}
opcion = ""
while opcion != "0":

    elif opcion == "4":
        for puesto, (nombre, prom) in enumerate(ranking(datos), start=1):
            print(f"  {puesto}. {nombre} ({prom:.2f})")
    elif opcion == "5":
        if eliminar_alumno(datos, input("Eliminar: ")):
            print("  Eliminado")
        else:
            print("  No existe")
    elif opcion != "0":
        print("  Opción inválida")
print("Fin del programa")
